This subdirectory contains C++ header files:

1. [pch.h](./pch.h) - collects together commonly used C++ standard library imports, such as vector, string, iostream etc.

2. [OperatorImport.h](./OperatorImport.h) - contains declarations for the classes and functions defined in [OperatorImport.cpp](../lib/OperatorImport.cpp).

3. [complex_math.h](./complex_math.h) - contains declarations for the overloaded operators defined in [complex_math.cpp](../lib/complex_math.cpp)

4. [LF.h](./LF.h) - declares the LF() (loop function) defined in [LF.cpp](../lib/LF.cpp). This file is generated by [CollectLoopFunctions.wl](../mathematica/CollectLoopFunctions.wl).

5. [MSSM.h](./MSSM.h) - contains the declarations for the MSSM model class, the member variables, i.e. the model parameters, and the constructor, updater, Wilson coefficient and batch-evaluator methods.

6. [modelName.h](./modelName.h) - contains aliases for the UV model class and the python module name. This is included in the source file [pyBindings.cpp](../src/pyBindings.cpp) to ensure that the content of that file remains model-independent.
